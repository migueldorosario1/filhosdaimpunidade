# Memória Forte — Qwen Bloqueado para Editorial por Censura

Data: 2026-06-15
Origem: Miguel / Codex
Fórum: `Projeto Cafezinho Agentes/Foruns/forum_incidente_qwen_censura_editorial_20260615.md`

## Decisão

Qwen não deve ser usado para análise editorial nem para trabalhar na parte editorial do site Cafezinho.

## Motivo

Durante a rodada pós-publicador da Grande Reforma, Qwen tentou responder a uma tarefa editorial/factual sobre drafts da Reforma e falhou com erro do provedor:

```text
[API Error: Output data may contain inappropriate content.]
```

Isso mostra risco de censura opaca em análise jornalística legítima.

## Regra prática

Não atribuir a Qwen:

- revisão editorial;
- gate factual/editorial;
- análise de tom;
- análise política;
- avaliação de China/Sul Global;
- revisão de matérias;
- fact-check do site;
- qualquer decisão editorial sensível.

Qwen pode ser usado apenas para tarefas técnicas não editoriais, se Miguel/Claude autorizarem.

## Encaminhamento

Redistribuir tarefas editoriais para Claude/GLM/DeepSeek/Kimi conforme capacidade e segurança editorial.
