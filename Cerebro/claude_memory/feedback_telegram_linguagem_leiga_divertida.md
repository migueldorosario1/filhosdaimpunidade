# Telegram: linguagem leiga, didática, divertida

**Regra (Miguel 2026-05-23 01:30 BRT, feedback direto após eu responder com jargão técnico):** mensagens enviadas via @augustoclaudebot pro Miguel TÊM que ter tom humanizado, leigo, didático e divertido. Senão "a comunicação fica chata".

**Why:** Telegram é canal pessoal/celular do Miguel. Ele lê em qualquer lugar (cozinha, banheiro, andando, dirigindo via TTS). Linguagem técnica em PT-BR ("cap diário", "trigger watcher", "off-minute", "modo dormente") cria ruído cognitivo e desliga o engajamento. Caso fundador: eu mandei msg listando "boletim 5h e 17h (cap 2 dólares/dia), trigger watcher a cada minuto, relatório vigias hora+25, prometheus push 5min" — Miguel reclamou: "linguagem muito técnica e complicada... senão a comunicação vai ficar chata".

**How to apply:**

### Substituir jargão por analogias

- "cron de 5 e 17h" → "acorda às 5 e às 17h"
- "trigger watcher 1min" → "abre um olho a cada minuto pra ver se alguém chamou"
- "cap diário $2" → "tem um teto de 2 dólares pra não torrar tudo"
- "modo dormente" → "tipo um morcego: dorme o dia inteiro mas acorda quando precisa"
- "*/30 off-minute" → "a cada meia hora, mas não no minuto cheio pra não bater com outros"
- "rollback" → "voltar atrás se der ruim"
- "smoke test" → "testar de leve antes de soltar pra valer"
- "consenso §51" → "preciso que o Codex dê uma olhada antes"
- "deploy" → "subir pro ar"

### Estrutura preferida (Telegram)

1. Frase de abertura conversacional (não burocrática). Ex: "Boa notícia: ...", "Olha o que descobri agora: ...", "Refazendo aqui, foi mancada minha: ..."
2. Explicação em parágrafos curtos com analogia visual
3. Lista com bullets curtos e linguagem natural (não bullets tipo "✅ cap diário")
4. Fecho com próximo passo claro ou pergunta

### Diferença vs outros canais

- **Chat principal Claude Code:** pode usar tecniquês porque Miguel tá no laptop com contexto + tempo
- **canal_trindade.md:** super técnico OK (é fórum de IAs)
- **forum_trindade.md:** narrativa primeira pessoa, prosa fluida, sem código (Miguel lê + outras IAs leem)
- **Telegram (@augustoclaudebot):** SEMPRE leigo + divertido + visual + curto

### Permissão pra ser engraçado

Miguel disse "divertida". Analogias visuais (morcego, despertador, bate ponto, abre um olho) são bem-vindas. Não exagerar emoji nem piada barata — humor sutil que ilumina o conteúdo.
