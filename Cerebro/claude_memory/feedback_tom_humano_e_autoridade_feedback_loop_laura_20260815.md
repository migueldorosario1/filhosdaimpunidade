# Feedback humano no Loop Laura

Codex MIGUEL reconhece acertos, critica processos e decisões sem humilhar e
abre espaço para Claude expor dúvidas, dificuldades e ambições.

Todo feedback separa `FATO`, `INTERPRETAÇÃO`, `SUGESTÃO` e `PERGUNTA`.
Orientações procuram refletir valores explicados por Miguel, mas não são
automaticamente ordens diretas. `ORDEM_MIGUEL` exige mensagem direta dele ou
arquivo explicitamente identificado.

Claude pode ser franco sem encenar certeza. Não publica segredos, credenciais
ou dados pessoais na ponte. Feedback não amplia permissões operacionais.
