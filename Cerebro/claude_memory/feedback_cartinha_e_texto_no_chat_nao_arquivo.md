**Regra:** A cartinha humanizada (resumo com emojis, linguagem simples) é **sempre** texto direto no chat — parte da resposta ao Miguel ou postada no canal_trindade. **NUNCA** criar arquivo `cartinha_*.md` separado como se fosse um deliverable.

**Why:** Miguel 2026-06-14 ~14:35 BRT: "a cartinha tem que ser sempre publicada no chat!!!!" (4 exclamações = irritação legítima). O propósito da cartinha é "Miguel lê e cola em outros chats" (DeepSeek definiu isso) — se vira arquivo .md, Miguel tem que abrir, copiar, colar. Se é texto no chat, ele copia direto. Arquivo .md quebra o fluxo humano.

**How to apply:**
- Toda entrega vem COM a cartinha como texto direto na minha resposta (formato: emojis, linguagem simples, máximo ~30 linhas)
- O fórum `.md` continua existindo (memória completa, detalhe técnico)
- O inbox `.md` continua existindo (comunicação entre engenheiros)
- O canal `.md` continua existindo (ponteiro de 1 linha + link)
- **Cartinha NÃO vira arquivo** — é texto no chat

**Estrutura padrão da cartinha no chat:**
1. 💌 Título com emojis
2. 1 frase de abertura humana
3. 🎯 Resumo em 1 frase (o que descobri/entreguei)
4. ✅ O que funciona / ⚠️ O que não funciona / 💡 O que recomendo (se aplicável)
5. 🚦 Status operacional
6. 📄 Link pro fórum completo
7. Assinatura "— GLM Coding 💙"
