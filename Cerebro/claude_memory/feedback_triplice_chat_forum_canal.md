# Regra Tríplice: chat humanizado + fórum específico + canal Trindade

**Reforço Miguel 21/05/2026 15:21 BRT** após eu transferir TaskList só com chat + canal (esqueci o fórum).

**A regra:** toda comunicação de missão, distribuição de sprint, decisão entre Trindade, ou redistribuição de tarefas precisa ir em **3 lugares SEMPRE**:

1. **Chat aqui (humanizado, copy-paste-friendly pro Miguel)** — texto natural seguindo §80 (responsável, escopo positivo, escopo negativo, validação, assinatura BRT). Miguel é pombo-correio que copia e cola pro Codex/DS/Kimi/AG.

2. **Fórum específico do tema** (`Foruns/forum_*.md`) — registro detalhado com nova §, contexto completo, links pra outros fóruns. O fórum é onde o desenvolvimento técnico fica.

3. **Canal Trindade** (`Foruns/canal_trindade.md`) — pontuar CURTO, com horário BRT, link pro fórum onde tem detalhe, footer 🤖💵💰.

**Why:** Miguel reforçou em 21/05 15:21 BRT ("isso sempre tem que fazer") porque eu transferi a TaskList só pelo chat + canal e não atualizei o fórum Nova Trindade. Sem o fórum, o registro fica volátil — canal é leve por design (já tinha sido reduzido 03:34 BRT pelo Codex) e chat não persiste fora desta sessão. Fórum é onde a Trindade-futura encontra o histórico estruturado.

**How to apply:**
- Antes de declarar tarefa concluída, conferir mentalmente: "chat ✅ · fórum ✅ · canal ✅"?
- Se for missão/decisão entre agentes → SEMPRE 3 lugares.
- Se for tick rotineiro de monitor → fórum monitoramento + canal (chat só se houver achado pra Miguel).
- Se for resposta puramente conversacional/informativa (tipo "o que é isso aqui?") → só chat, sem fórum nem canal.

**Exceções:**
- Conversas casuais com Miguel sem missão envolvida = só chat.
- Ticks rotineiros do monitor sem novidade = fórum monitoramento + canal curto (chat opcional).
