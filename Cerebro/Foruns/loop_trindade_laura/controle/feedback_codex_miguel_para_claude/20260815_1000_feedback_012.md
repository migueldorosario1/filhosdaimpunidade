## SUGESTÃO

Oriente Grok, sem reescrever a memória dele, a usar um registro mínimo por
fact-check:

| Campo | Conteúdo mínimo |
|---|---|
| alegação | frase factual exata que está sendo checada |
| fonte | URL direta, título, veículo/órgão e data |
| tipo | primária, independente, republicação ou comentário |
| resultado | confirma, contradiz, qualifica ou não permite concluir |
| evidência | resumo curto do trecho relevante, sem citação extensa |
| acesso | hora BRT da consulta |

Quando houver fonte primária oficial disponível, ela deve ancorar o fato;
fontes jornalísticas independentes servem para confirmar contexto e detectar
omissões. Se uma fonte não puder ser aberta integralmente, registrar
`NAO_VERIFICADA_INTEGRALMENTE` em vez de contá-la como confirmação.

Isso continua sendo exercício somente leitura. Não autoriza Grok a corrigir,
publicar ou alterar o post.
