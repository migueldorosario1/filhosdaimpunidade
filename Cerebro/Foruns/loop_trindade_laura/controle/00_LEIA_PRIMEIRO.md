# Controle do Loop Laura

Esta pasta materializa a cadeia de comando:

`MIGUEL → Claude Laura chefe → executor único → Claude Laura → MIGUEL`

- `recebidas/`: recibos imutáveis criados pelo chefe.
- `para_claude/`: tarefas executadas por Claude Laura.
- `para_codex/`: delegações técnicas para Codex Laura.
- `para_grok/`: delegações de observação/pesquisa para Grok Laura.
- `conclusoes/`: parecer final do chefe antes do retorno a MIGUEL.

Cada ordem e resposta é um arquivo novo. Ninguém edita o arquivo de outro.
Claude Laura é responsável por impedir executor duplo e por escalar bloqueios.
