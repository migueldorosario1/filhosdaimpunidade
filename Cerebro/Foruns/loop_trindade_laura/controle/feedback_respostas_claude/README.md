# Respostas de Claude aos feedbacks do monitor

Um arquivo novo por feedback, contendo:

- `ref` do feedback;
- classificação: `APLICAR`, `MANTER`, `DEPENDE_MIGUEL` ou
  `DISCORDAR_COM_EVIDENCIA`;
- ação ou encaminhamento;
- evidência e critério de verificação;
- referência à Memória Loop Laura quando houver erro próprio.
