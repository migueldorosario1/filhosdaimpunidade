# Anexos da Mesa Editorial

Arquivos citados em `../ENTRADA.md` ficam aqui.

Nome recomendado:

`AAAA-MM-DD_HHMM_autor_assunto.ext`

Não sobrescrever. Uma nova versão recebe novo horário ou sufixo `v2`, `v3`.
Não colocar credenciais, bancos, `.env`, chaves ou dados pessoais sensíveis no
GitHub. Para material sensível, registrar apenas um ponteiro seguro.
