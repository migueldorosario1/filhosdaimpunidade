**Risco:** Se isso acontecer durante uma janela crítica de publicação, o Sentinela pode pular correção de imagem em draft elegível.

**Ação proposta:**
```python
# Em vez de falhar silenciosamente, adicionar retry com backoff
# E se falhar 2x consecutivas, elevar para alerta P3

# Pseudocódigo:
def check_v4_pipeline_imagem(max_retries=2):
    for attempt in range(max_retries):
        try:
            result = _do_check()
            return {"ok": True, **result}
        except TimeoutError:
            if attempt == max_retries - 1:
                return {"ok": False, "erro": "timeout após retry", "alerta": "P3"}
            time.sleep(2 ** attempt)
```

**Prioridade:** Baixa-média. Intermitente, mas vale instrumentar.
