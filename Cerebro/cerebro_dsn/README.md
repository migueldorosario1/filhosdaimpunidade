# 🧠 cerebro_dsn — Mini-cérebros dos DSNs (modelo simplificado do Cérebro Imortal)

> **Ordem do Miguel 01/09/2026 ~19:2x:** "cada DSN precisa de um cérebro próprio — modelo simplificado do Cérebro Imortal: arquivos próprios, indexados, indexáveis, memória." Desenho aprovado ("vai"): ZM propôs mini-cérebro leve.

## Estrutura (por robô)
- `MEMORIA_VIVA.md` — ≤80 linhas: identidade, regras, lições com data. **Lida e injetada no prompt de TODO ciclo** (~1.500 tokens).
- `INDEC.md` — índice de 1 tela, só links (regra de ouro das 3 camadas em miniatura).
- `licoes/` — aprendizados datados: **o quê / por quê / como aplicar**.
- `casos/` — fichas do que o robô processou (post, veredito, motivo).

## Regras do mini-cérebro
1. **Nada de copiar a casa:** Manual de Estilo, diretrizes vivas e o Cérebro Imortal são REFERENCIADOS por link, nunca duplicados (senão divergem).
2. **Escrita estruturada:** lição nova = arquivo datado com o quê/por quê/como aplicar; linha nova na VIVA só quando madura.
3. **Poda é rito:** revisão periódica (ronda do Chefe): lição madura → VIVA; lição morta → arquivada. Sem poda vira diário.
4. **Versionado no repo:** tudo vive aqui (Git) — toda instância (Dell/Tencent/Laura/WP) lê e escreve pela mesma fonte.
5. **Leveza na força:** carrega só VIVA+INDEC; detalhe abre-se por arquivo quando o caso pede (grep/find; sem banco por enquanto).
